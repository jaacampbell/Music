# AGENTS.md

## Project overview

`Music` is a single-page **Vite + React + TypeScript** app. It is a music player
whose audio is synthesized at runtime via the Web Audio API (no audio assets).
Key files: `src/synth.ts` (audio engine), `src/tracks.ts` (procedural tracks),
`src/App.tsx` (UI + visualizer).

## Cursor Cloud specific instructions

- Standard commands are defined in `package.json` and documented in `README.md`
  (`npm run dev`, `npm run build`, `npm run lint`, `npm run preview`). Use those
  rather than duplicating them.
- This is a single frontend service. `npm run dev` serves it at
  `http://localhost:5173` (Vite). There is no backend, database, or env/secret
  configuration.
- Audio is generated by the Web Audio API. Browsers require a user gesture before
  an `AudioContext` will produce sound, so playback only starts after a click on
  a track or the play button — this is expected, not a bug.
- When verifying in a headless/automated browser there may be no audible output,
  but correctness is still observable visually: the seek time advances and the
  frequency-bar visualizer animates while a track plays.
- `npm run build` runs `tsc -b` first, so type errors fail the build.
